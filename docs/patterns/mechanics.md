# Cross-Cutting Mechanics

Whole named mechanics spanning trigger+cost+static (Monarch, Ring tempts, Blitz, Adventure, Storm-adjacent, additional combat). Part of the card-implementation pattern catalog — see `docs/card_patterns.md` for the index.

**Casting a card from its own graveyard with extra costs** (Demonic Embrace): the card defines `may_cast_from_graveyard? = zone&.graveyard? || false` (`Action#in_permitted_zone?` reads it) and `additional_costs` returning `[Costs::PayLife.new(self, amount: 3), Costs::Discard.new(owner)]` while it is in the graveyard. Pay them on the cast with `pay_additional_life` (the life is lost as the spell is cast) and `pay_discard(card)`. Example: `DemonicEmbrace`.

**A discard-from-hand ability that is not cycling's draw** (Waker of Waves: "{1}{U}, Discard this card: Look at the top two cards ..."): declare `cycling "{1}{U}"` and override `cycling_effect!` (what happens after the discard; default draws, or searches for landcycling). Example: `WakerOfWaves`.

**"Spend this mana only to cast an instant or sorcery spell"**: a `TapManaAbility` with `mana_restriction = ManaRestriction::InstantOrSorcerySpell.new`, `choices :colorless` and `mana_produced = { colorless: 1 }`. Example: `VodalianArcanist`.

**"Creatures you control attack each combat if able" (a static effect, not on the creature itself)**: subclass `Abilities::Static::MustAttack` and implement `applies_to?(permanent)`; `Permanent#must_attack?` asks every such ability on the battlefield. A token can carry static abilities. Example: `PursuedWhale`'s Pirate token.

**"Spells your opponents cast that target this cost {N} more"**: a static ability answering `cost_increase_for_targeting(card, targets, player)` with the extra generic mana. `Actions::Cast#targeting` adds it to what is owed (`Costs::Mana#increase_generic!`, which keeps payments already made), so the caller pays the extra after `targeting` with a second `pay_mana`, or the cast fails with `OutstandingBalance`. Example: `PursuedWhale`.

**Monarch**: Implemented as a real cross-cutting game mechanic, not a per-card flag. `Game#monarch` / `Game#make_monarch!(player)` (notifies `Events::PlayerBecameMonarch`); `Player#monarch?` / `Player#become_monarch!`. `Game` subscribes to its own events (`subscribe(self)` in `initialize`) and its `receive_event` handles the two game-rule effects that aren't tied to any specific card: the monarch draws a card at the beginning of their own end step (`Events::BeginningOfEndStep`, compares `event.active_player`), and a creature dealing combat damage to the monarch transfers the monarchy to that creature's controller (`Events::CombatDamageDealt`, checks `event.target == monarch`). A card that grants monarch status (e.g. "you become the monarch" on ETB) only needs to call `actor.controller.become_monarch!` — the draw-each-end-step and combat-damage-transfer rules apply automatically regardless of which card granted it. Example: `CourtOfBounty`; mechanic tests live in `spec/game_spec.rb` rather than a card spec.

**"The Ring tempts you"** (LOTR "Ring-bearer" mechanic): Implemented as a real cross-cutting game mechanic, like Monarch above, not a per-card flag — only the "gain an emblem, level it up, choose a Ring-bearer" state machine is built so far, not the four abilities the emblem's levels grant (see below). `Game#the_ring_tempts!(player)` finds or creates that player's `Emblem::TheRing` (via `Game#ring_emblem_for(player)`, `emblems.find { it.is_a?(Emblem::TheRing) && it.owner == player }` — emblems dedupe per player, unlike a plain `game.add_emblem(Emblem.new(...))` which always adds a fresh one), calls `emblem.gain_next_ability!` (bumps `level`, capped at `Emblem::TheRing::MAX_LEVEL = 4`), notifies `Events::TheRingTemptsPlayer`, then — mandatory, not a `Choice::May`, matching the Oracle wording "you must choose a creature if you control one" — adds a `Choice::RingBearer.new(player:)` only if `player.creatures.any?` (the usual "if you can't" empty-pool guard). `Choice::RingBearer < Magic::Choice::Targeted` overrides `controller` to return the explicit `player:` ivar rather than the usual `actor.controller` (same reason as `RuthlessWinnower`'s edict choice: `actor` here is the `Player`, not a permanent/card, so there's no natural `.controller` to delegate to), and its `resolve!(target:)` clears the old `Permanent#ring_bearer` flag, sets the new one, and updates `Player#ring_bearer` (both plain `attr_accessor`s, mirroring `chosen_creature_type`). A card that triggers a tempt (e.g. "when this enters, the Ring tempts you") only needs `game.the_ring_tempts!(actor.controller)` from a simple ETB block. **Not yet implemented**: the four Ring abilities' actual effects (Ring-bearer is legendary and can't be blocked by greater power; draw-then-discard on Ring-bearer attack; Ring-bearer's blocker sacrifices itself at end of combat; Ring-bearer combat damage to a player drains each opponent for 3) — `Emblem::TheRing#level` tracks how many the player has, but nothing reads it yet. Add those as they're needed by a card that actually depends on them, the same way `Abilities::Static::*` classes get added on demand. Example: `FieryInscription`.

**"You may cast instant and sorcery spells from your graveyard. If a spell cast this way would be put into your graveyard, exile it instead."** (Jaya Ballard-style graveyard-casting emblem): `Magic::Emblem` gained two default-`false` hooks, `permits_casting_from_graveyard?(card)` and `exiles_after_graveyard_cast?(card)`, mirroring the `permits_casting_from_exile?`/`permits_casting_from_top?` hooks `Abilities::Static::*` classes already expose — `Actions::Cast#can_perform?` ORs in a `from_graveyard` check (`card.zone&.graveyard? && game.emblems.any? { |e| e.owner == player && e.respond_to?(:permits_casting_from_graveyard?) && e.permits_casting_from_graveyard?(card) }`), and `#resolve!`'s sorcery/instant zone-move branch checks the same emblems for `exiles_after_graveyard_cast?` before falling through to the normal `card.move_to_graveyard!` — same `card.zone&.graveyard?` guard (not `.graveyard?` unguarded: by the time `resolve!`'s zone-move branch runs, `card.zone` is `nil` for an ordinary hand-cast spell, so the unguarded call raises `NoMethodError` for every other spell in the suite). No mana-cost special-casing needed — `@flashback` stays `false` for this path, so `mana_cost` already falls through to the card's normal `cost`. A card's own emblem subclass only needs to override the two hooks (`card.instant? || card.sorcery?` for the permission, unconditional `true` for the exile). As with the cast-count-limit note above, `can_perform?` is advisory only — the actual cast in a spec just builds/pays/resolves a `Cast` action directly, same as any other spell. Example: `JayaBallard`.

**"You can cast only one more spell this turn" (or any other turn-scoped cast-count restriction)**: Unlike most cost/targeting restrictions in this file, this one is actually enforced — `Actions::Cast#can_perform?` is never consulted by `perform`/`take_action` (see `Ephemerate`/`DeflectingSwat` notes), so the check has to live in `perform` itself. `Player` has `limit_spells_this_turn!(n)` (sets `spell_cast_limit` + stamps `spell_cast_limit_turn = game.current_turn.number`, the same turn-number-stamp pattern as `SerpentsSoulJar`'s `exile_cast_permission_turn` — naturally expires once the turn advances, no cleanup step needed), `spell_cast_limited?` (true only while that stamp matches the current turn), `spell_cast_limit_reached?` (limited and count is `0`), and `consume_spell_cast!` (decrements, no-op when not limited). `Actions::Cast#perform` raises `Actions::Cast::SpellCastLimitReached` up front — before additional costs or mana are paid — if `player.spell_cast_limit_reached?`, then calls `player.consume_spell_cast!` right after `mana_cost.finalize!(player)` so every successful cast (not just the first) counts against the limit. A card sets it from its own `resolve!` (`controller.limit_spells_this_turn!(1)`) — the card's own cast already happened before `resolve!` runs, so the count only ever covers casts *after* it. Example: `IrencragFeat`.

**Blitz** ("You may cast this spell for its blitz cost. If you do, it gains haste and 'When this creature dies, draw a card.' Sacrifice it at the beginning of the next end step."): Implemented generically, mirroring `flashback`/`rebound`. `Card.blitz(cost)` DSL macro stores the raw cost hash as a `BLITZ_COST` constant (`const_set`, same shape as the plain `cost(cost)` macro) — **don't** pass a pre-built `Costs::Mana` instance like `flashback` does; `Card#blitz_cost` (base implementation) builds a *fresh* `Costs::Mana.new(self.class::BLITZ_COST.dup)` on every call. This matters because `Costs::Mana#dup` is a shallow copy — the duped object still aliases the original's `@balance` Hash, so paying down a `Costs::Mana` singleton shared across casts (as `flashback`'s `cost`-object-literal pattern does) permanently mutates that shared balance and the next cast to reuse it raises a bogus `Overpayment`. Building the cost fresh from a plain Hash each time sidesteps this. `Actions::Cast::Blitz` (a `Cast` subclass, like `Cast::Flashback`) overrides `base_cost` to read `card.blitz_cost`, and its `after_resolving` hook — after the card resolves as a permanent — calls `grant_haste!` and registers `Magic::Blitz::DeathDrawTrigger` (`Events::CreatureDied`, guarded by `this?`) and `Magic::Blitz::EndStepSacrificeTrigger` (`Events::BeginningOfEndStep`, unconditional `actor.sacrifice!`) via `register_turn_trigger` — both live in `lib/magic/blitz/` as small reusable `TriggeredAbility` subclasses. Drive it in specs with `player.cast_as(:blitz, card:) { |a| a.pay_mana(...) }` (paying `card.blitz_cost`'s mana value, not the normal `cost`). The same two `Blitz::*Trigger` classes are reusable for any other "hasty, draws a card on death, sac'd at next end step" effect that isn't the blitz keyword itself — e.g. a token-copy ability with that exact wording — just `register_turn_trigger` them directly on the resulting permanent instead of duplicating card-local trigger classes. Example: `JaxisTheTroublemaker` (both the keyword and its activated ability use them).

**Offspring** ("You may pay an additional {N} as you cast this spell. If you do, when this creature enters, create a 1/1 token copy of it."), and "creature spells you cast gain offspring {N}": a card's own offspring is the `offspring generic: 1, red: 1` DSL macro (`Card#offspring_cost` returns the raw cost or nil). `Actions::Cast#offspring_costs` lists the card's own cost first, then one per `Abilities::Static::GrantOffspring#offspring_cost_for(card, player)` on the battlefield, each wrapped in a `Costs::Kicker` — they are separate additional costs, so a spell can have several (Agate Instigator under Zinnia). `action.pay_offspring(payment)` pays the next unpaid one in that order (matched by identity, since two equal `{2}` grants compare `==`); call it once per cost you want. Unlike kicker, `perform` finalizes every paid offspring cost, so the mana actually leaves the pool. On resolution `Cast#resolve!` finds the creature's `EnteredTheBattlefield` event and fires `Offspring::TokenCopyTrigger` once per paid cost through `Permanent#perform_trigger!` (public, so doublers still apply); each makes a `token: true, copy: true` copy of `copiable_card` with permanent base power/toughness 1/1 via `modify_base_power(1, until_eot: false)`. Examples: `AgateInstigator` (own offspring, plus the pay-both test), `ZinniaValleysVoice` (grants it).

**Adventure** (a card castable either as itself, or — earlier or later, from hand — as a differently-named/costed/typed spell that exiles instead of going to the graveyard, playable later as the "real" card from exile): No existing mechanism covered a second, fully independent cost/effect/type living on the same `Card` object, so this added generic `Actions::Cast` support rather than a card-local hack. `Card.adventure(cost)` DSL macro (mirrors `blitz`) stores `ADVENTURE_COST`; `Card#adventure_cost` (mirrors `blitz_cost`) builds a fresh `Costs::Mana` from it on every call, same shallow-`dup`-aliasing reason `blitz_cost` does. `Actions::Cast::Adventure` is a third `Cast` subclass alongside `Flashback`/`Blitz`: its `base_cost` reads `card.adventure_cost` instead of `card.cost`; its `resolve_method` makes `resolve!` call `card.adventure_resolve!(...)` instead of `card.resolve!(...)` (via a `method:` keyword on `ResolvesWithArgs#resolve_with_args`, so the same keyword-filtering logic works against either method name) and its `move_after_resolving` then unconditionally `card.exile!`s the card afterward regardless of the card's own type — this is what makes the *other* face playable later, since `Actions::PlayLand`/`Card#resolve!` have no zone restriction of their own (PlayLand just calls `card.resolve!`, `Player#cast`'s `can_perform?` isn't consulted by `perform`/`take_action`, only by specs). Define `adventure_resolve!` directly on the card class (separate from the type-line-driven `resolve!` used for the card's normal/permanent side — e.g. a land Adventure keeps `type T::Land, ...` and its default `resolve!` still makes a Permanent when played as a land, while `adventure_resolve!` is a distinct method for the spell-side effect, not a variant of `resolve!` gated by a flag). Drive it in specs with `player.cast_as(:adventure, card:) { |a| a.pay_mana(...) }`, exactly like a normal cast. Example: `LindblumIndustrialRegency` (Land — Town front face; "Mage Siege" {2}{R} Instant — Adventure back face creates a 0/1 black Wizard token).

**Additional combat phase** (`game.current_turn.queue_additional_combat!` / `additional_combat_pending?` on `Game::Turn`, `lib/magic/game/turn.rb`): this state-machine plumbing already existed but had never been exercised by a card — the `second_main` event correctly transitions `end_of_combat: :beginning_of_combat` `if: :additional_combat_pending?`, but nothing ever decremented `@additional_combats`, so once *any* card queued one, every future `second_main!` for the rest of the game would keep re-triggering "one more" additional combat forever instead of exactly the number queued. Fixed by adding `after_transition from: :end_of_combat, to: :beginning_of_combat do |turn| turn.consume_additional_combat! end` (only fires on the transition actually gated by `additional_combat_pending?`) plus a `consume_additional_combat!` method decrementing the counter. No card needs to touch this directly — just call `queue_additional_combat!` once per extra combat phase the card grants (e.g. from an exert effect) and the state machine handles entering, then correctly not re-entering, the extra phase.

**`Actions::Cast#controller` is a dead reader — never actually assigned**: `Actions::Cast#initialize` accepts a `controller:` kwarg (default `card.controller`) but never stores it to `@controller`, so `attr_reader :controller` always returns `nil` for every `Actions::Cast` instance, including everything in `game.stack.spells`. Nothing else in the codebase reads it (every existing "spell you control" check reads `spell.card.controller` instead, e.g. `Reiterate`, `RinAndSeriInseperable`), so this has shipped silently broken. Don't call `.controller` on a stack item pulled from `game.stack.spells`/`game.stack.abilities` — use `.card.controller` instead. Discovered implementing `TwinningStaff`'s "target instant or sorcery spell you control."

**Proliferate** ("Choose any number of permanents and/or players, then give each another counter of each kind already there."): `Magic::Choice::Proliferate` (`lib/magic/choice/proliferate.rb`) is a plain `Magic::Choice`, not wrapped in `Choice::May` — "any number, including none" is expressed by defaulting `resolve!(chosen: [])` rather than by a separate accept/decline step. `choices` is `game.battlefield.select { |p| p.counters.any? } + game.players.select { |pl| pl.counters.any? }` (both `Permanent#counters` and `Player#counters` are populated `Counters::Collection`s already); `resolve!` groups each chosen entity's own counters by `.class` and calls `entity.add_counter(counter_class)` once per distinct class present — both `Permanent#add_counter` and `Player#add_counter` accept a counter *class* directly (`Counters.[]` special-cases `return counter_type if counter_type.is_a?(Class)`), so there's no need to map back to the string keys (`"+1/+1"`, etc.). A card just calls `proliferate` (`proliferate(source)` where there is no `actor`) wherever its own trigger says "proliferate" — no per-card class needed. Example: `CacophonyScamp` (as the payoff for "you may sacrifice it. If you do, proliferate.").

**Cycling** ("{cost}, Discard this card: Draw a card."): No existing mechanism let a `Card` sitting in hand activate anything — `Card#activated_abilities` returns raw ability *classes* (only `Permanents::ContinuousEffects#calculate_activated_abililities` ever instantiates them, battlefield-only), so `FesteringThicket`'s land-cycling ability was dead code, only reachable (and only tested) once the land was already a permanent. Added a real hand-side path instead of reusing that: `Card.cycling(cost)` class macro (mirrors `blitz`/`adventure`) stores `CYCLING_COST`; `Card#cycling_cost` builds a fresh `Costs::Mana.new(self.class::CYCLING_COST.dup)` per call (same shallow-`dup`-aliasing reasoning as `blitz_cost`). `Actions::Cycle` (`lib/magic/actions/cycle.rb`) is a small standalone `Action` — no stack involvement needed, matching `Actions::PlayLand`'s directness — whose `perform` finalizes the mana cost, calls `card.discard!` (already existed, just previously unused for a self-inflicted cost), then `card.trigger_effect(:draw_cards, number_to_draw: 1)` (works after the discard since it's just metadata read off the `Card`, whose `controller` doesn't change on a zone move). Wired via `Player#cycle(card:) { |a| a.pay_mana(...) }`, mirroring `Player#play_land`. Card side is just the DSL macro plus `game.take_action` doesn't need touching. Example: `SparkSpray`.

**Hideaway N ("look at the top N cards, exile one face down, put the rest on the bottom in a random order") and "you may play the exiled card"**: An ETB trigger takes `controller.library.take(N)` and pushes a `Choice::Targeted` whose `choices` are those cards; `resolve!(target:)` does `target.exile!`, `actor.exiled_cards << target` (the permanent remembers it, like `GraspOfFate`), then removes the rest from the library and re-adds each with `library.add(card, library.count)` — **not** `library.count + index`, since `count` grows on every insert and the index then overshoots, padding the array with `nil`s (`NessianWanderer` still has that bug). The later payoff is a `Choice::May` whose `resolve!` does `actor.remove_from_exile(card)` then `controller.cast(card:, by_effect: true) { _1.mana_cost = 0 }`, the same free cast as `IdolOfEndurance`. Lands are skipped when the payoff is outside a main phase (a land can't be played then). Free-casting a spell that needs targets isn't handled. Example: `FightRigging`.

**"If that creature would die this turn, exile it instead"** (a replacement effect on one permanent that lapses at end of turn): `Permanent#register_turn_replacement(matcher, replacement_class)` adds a `[matcher, ReplacementEffect]` pair consulted by `replacement_effect_for` alongside the card's own `replacement_effects`, and is cleared in `Permanent#cleanup!` (the cleanup step; a spec needs `current_turn.end!` then `current_turn.cleanup!`, `game.next_turn` alone doesn't). `Magic::ReplacementEffect::ExileInsteadOfDying` is the reusable replacement (`MovePermanentZone` from the battlefield to a graveyard for that permanent becomes `Effects::ExilePermanent`); register it right after the damage: `target.register_turn_replacement(Magic::Effects::MovePermanentZone, Magic::ReplacementEffect::ExileInsteadOfDying)`. An exiled permanent's card is in `game.exile`, not `player.exile`: assert with `card.zone` `be_exile`. Example: `FeedTheFlames`.
**"Can't be countered" / countering everything an opponent controls**: `cant_be_countered` in the DSL block. To counter spells or abilities en masse, filter `game.stack.spells` (a `Cast` action: `.player`, `.card`) and `game.stack.abilities` (`ActivateAbility#player` or `TriggeredAbility#controller`) and use `trigger_effect(:counter_spell / :counter_ability, target:)`; skip spells whose `card.can_be_countered?` is false. Triggered abilities usually resolve at once rather than using the stack. Example: `GlenElendrasAnswer`.

**An activated ability the card has while sitting in the graveyard** ("{cost}: Return this card from your graveyard to your hand.", or any other graveyard-activatable ability): no new `Action` class needed. `Actions::ActivateAbility#illegal_reason` already only checks `source.controller`/`source.can_activate_ability?` generically (skipped when `source` doesn't respond to the latter, true for a bare `Card`) and `ability.requirements_met?` — so give the ability class its own `requirements_met?` gating on `source.zone&.graveyard? && source.owner == controller && game.can_cast_sorcery?(controller)` (swap the zone/timing check for whatever the card actually needs), and a card-level reader (not `activated_abilities`, which only `Permanent` instances expose to the battlefield machinery) returning instances built with `source: self`: `def graveyard_abilities = [GraveyardAbility.new(source: self)]`. Drive it in specs exactly like any other activated ability: `player.activate_ability(ability: card.graveyard_abilities.first) { |a| a.pay_mana(...) }`. Example: `EvershrikesGift`.

**Vivid ("the number of colors among permanents you control")**: `Player#colors_among_permanents` (distinct colors over `permanents`' `Permanent#colors`, so a hybrid or colour-set permanent counts correctly). ETB draws/life/damage read it at resolution (`Luminollusk`, `Shinestriker`, `Shimmercreep`, `ExplosiveProdigy`). "Up to X targets" is a `Choice::Targeted` with `choice_amount = 0..controller.colors_among_permanents` and `resolve!(targets:)` (`Prismabasher`); a choice with exactly one legal target and a non-zero minimum resolves itself, so a spec has no pending choice to answer. A self cost reduction ("this spell costs {1} less for each ...") can't be a battlefield static ability, since the card is in hand: override `Card#self_mana_cost_adjustment` (a hash for `Costs::Mana#adjusted_by`; values may be lambdas evaluated at cast time), which `Actions::Cast#mana_cost` applies (`WildvinePummeler`). "Reveal until X permanent cards ... put any number onto the battlefield" is a custom `Choice` with `resolve!(cards:)` that calls `Permanent.put_onto_battlefield(...)` and sends the rest to the library bottom (`AuroraAwakener`). "You may cast the exiled cards this turn": `game.play_permissions.grant_until_end_of_turn(card:, player:)` (`SanarInnovativeFirstYear`; `grant_until_end_of_next_turn` is the longer one).

**"Choose a creature type" / "of the chosen type"**: for a permanent ("as this enters"), queue `Magic::Choice::ChooseCreatureTypeForPermanent.new(actor: actor[, options: [...]])` from an ETB trigger; it stores `Permanent#chosen_creature_type` and rejects a type outside `options` (`DawnBlessedPennant`'s fixed list). Read it back from `source.chosen_creature_type` in static abilities/triggers (`ChronicleOfVictory`, `GatheringStone`). A follow-up that needs the type (Gathering Stone's "look at the top card") subclasses the choice and does its work after `super`, because two separate ETB triggers have no guaranteed order. For a spell ("choose a creature type. Draw a card for each ...") the card's `resolve!` adds a `Choice::CreatureType` subclass whose `resolve!(creature_type:)` does the effect (`BloodlineBidding`, `HarmonizedCrescendo`). "Double all damage that sources you control of the chosen type would deal": `ReplacementEffect::ChosenTypeDamageDoubler.registrations` as the card's `replacement_effects` (`CollectiveInferno`); it covers `DealDamage` and `DealCombatDamage`.

**Restricted mana ("spend this mana only to ...")**: a `ManaAbility` overrides `mana_restriction` to return a `Magic::ManaRestriction` (`ManaRestriction::ChosenType.new(source:)`; subclass and implement `permits?(use)` for others). `Player#add_mana(mana, restriction:)` then keeps each unit in `player.restricted_mana` (`RestrictedMana` = color + restriction) instead of `mana_pool`, which stays a plain color-to-count hash. `Costs::Mana#for_use` (set to the card by `Actions::Cast#mana_cost`; to `Actions::AbilityUse.new(source:)` by `ActivateAbility`, `Ninjutsu` and `Cycle`, so abilities used from hand or graveyard count as abilities and `AbilityUse#type?` forwards to the source; `Suspend` sets `Suspend::Use`, which is neither a spell nor an ability, so `ColorlessSpellOrAbility` refuses it) makes `can_pay?`/`auto_pay`/`finalize!` count the restricted mana that `use` permits, via `Player#spendable_mana_for(use)`; `Player#pay_mana(mana, for_use:)` spends permitted restricted mana before plain mana. Restricted mana never counts for a cost without a `for_use`. A spec must pay through `player.cast` (not `cast_and_resolve`, which doesn't pay costs) to see it spent. Example: `EclipsedRealms`.

**"Players can't draw cards or gain life"** (a global prohibition, not a replacement of one effect): `Player#draw!` and `Player#gain_life` check `can_draw?`/`can_gain_life?`, which ask every battlefield static ability that defines `prevents_drawing?(player)` / `prevents_life_gain?(player)`. Gating in `Player` (rather than a `ReplacementEffect` on `Effects::DrawCards`/`GainLife`) also covers the direct callers: the draw step, lifelink, `controller.gain_life(n)`. A prevented draw from an empty library doesn't lose the game. `Events::DrawStep` carries `player:` (the active player) for "at the beginning of each player's draw step" triggers; the effect may belong to the opponent, so a search "that player" does needs a `Choice` that overrides `controller` (`MornsongAria::SearchChoice`). Example: `MornsongAria`.

**Ward—Pay N life / "can't be countered"**: `ward life: N` (like `ward generic: N`) pushes a `Choice::Ward`; answer `game.resolve_choice!(pay_life: true)` to pay (`trigger_effect(:lose_life)`, refused if the payer has less than N life) or anything else to counter the spell/ability. "This spell can't be countered" is `cant_be_countered` in the DSL block; "spells you control can't be countered" is a static ability defining `prevents_countering?(card)` (`Card#can_be_countered?` asks every battlefield static ability; `CounterSpell` honours it). "Other creatures you control have ward": no way to grant a triggered ability yet, so the card adds its own `SpellCast`/`AbilityActivated` triggers that add a `Choice::Ward` per warded creature an opponent targets (merge into `super`'s handler arrays, not over them). Example: `HexingSquelcher`.

**Flashback with a non-mana requirement (e.g. "Behold three Elementals")**: beholding moves and taps nothing, so keep `flashback Costs::Mana.new(...)` for the mana and define `flashback_requirements_met?(player)` on the card; `Actions::Cast#illegal_reason` refuses a flashback cast while it returns false. Example: `KindleTheInnerFlame`.

**"Loses all creature types" until end of turn**: `permanent.lose_creature_types!` pushes a layer-4 `Modifications::LoseCreatureTypes`; `ContinuousEffects#calculate_types` strips every creature type and `Permanent#all_creature_types?` returns false, so it overrides changeling too. Example: `NamelessInversion`.

**"{cost}, Exile this card from your graveyard: ..." (self-exile from the graveyard)**: same `GraveyardAbility` shape as above, with `costs "{W}, Exile {this}"` (`Costs::SelfExile` works on a bare `Card`; pay it in specs with `.pay_mana(...).pay_self_exile`). `ActivateAbility` pays costs *before* it checks `requirements_met?`, so by then the card is already in exile — the zone check must accept `graveyard? || exile?`. Hybrid mana in the cost (`{1}{B/G}`) is paid with a plain colour key: `pay_mana(generic: { green: 1 }, green: 1)`. Examples: `GoldmeadowNomad`, `StoicGroveGuide`.

**Dream counters / "exile that card instead of putting it into your graveyard as it resolves" (Goliath Daydreamer)**: no general card-counter support; `Card#dream_counter` is a boolean that lasts while the card stays in exile (cleared in `Card#zone=`). A `SpellCast` trigger (from hand, instant/sorcery) sets `spell.exile_with_dream_counter = true`; the trigger resolves before the spell, and `Actions::Cast#resolve!` then exiles it and sets `dream_counter` instead of the graveyard move (the mark clears on any zone change, so a countered spell isn't exiled). Exile is one shared `game.exile` zone, not per-player: filter by `card.owner`. The free-cast attack trigger is a `Choice::May` subclass answered with `game.resolve_choice!(target: card, targets: [...])` (the targets the free spell needs). Example: `GoliathDaydreamer`.

**Double-faced cards (transform)**: the front face is the card (`Creature` etc. with `back_face BackClass`), the back face is a second `Card` subclass defined in the same file *before* the front (its own name, type line, P/T, abilities; no cost, so `color_indicator :black` gives its colours). `card.back_face` builds the (memoised) back-face instance, whose `mana_value` is the front's. `permanent.transform!` (no `card:`) turns the permanent over: `permanent.face` is the face up (`transformed?`), the physical `card` never changes (so it dies/bounces as the front face), continuous effects recompute names/types/P/T/keywords/activated abilities from `face`, and `Events::PermanentTransformed` fires. Static abilities, lifecycle triggers (`etb_triggers`...) and `event_handlers` are read from `face`, so each face lists its own; "whenever ~ enters or transforms into <this face>" is an `etb_triggers` class plus `Events::PermanentTransformed => SameLogic` (a handler on the face that's up only fires when transforming *into* it). "At the beginning of your first main phase, you may pay {X}. If you do, transform ~": subclass `TriggeredAbility::PayToTransform` with `pay black: 1` under `Events::FirstMainPhase` (it adds a `Choice::PayToTransform`, answered with `game.resolve_choice!(payment: nil)` to pay automatically, or `game.skip_choice!`). Example: `TrystanCallousCultivator`.

**Modal double-faced cards (MDFC), spell // land** (`RevitalizingRepast // OldGrowthGrove`, also the land // land `NeedlevergePathway`): same layout as a transform DFC (back-face land class defined first in the front's file, front says `back_face OldGrowthGrove`; the back has no cost, so in hand the card has only the front's name, type, cost and mana value). The front is cast normally (`p1.cast(card:)`). The back is played with `p1.play_land(land: card, face: :back)`: `PlayLand#perform` calls `Card#play_back_face!`, which enters the permanent already transformed (`Permanent.resolve_spell(transformed: true)`, no `PermanentTransformed` event), so the permanent is the land from the start, with the back face's `enters_tapped?`, abilities and ETB triggers; it uses the land drop and the card leaves hand. `Game#legal_actions` offers a `PlayLand(face: :back)` for every in-hand/playable-zone card whose `back_face` is a land, next to the `Cast` of the front. The back face's land type, abilities and `enters_tapped?` go in its own class (`def enters_tapped? = true`, `TapManaAbility` with `choices :black, :green`); activate a two-colour land with `{ _1.choose(:black) }`. A hybrid front cost (`cost black_or_green: 1`) is paid with the colour in the pool: `pay_mana(green: 1)`. Known gap: `LandsEnterUntapped` replacements test the front face (`card.land?`), so they don't apply to a spell-front MDFC land yet. **Pay-3-life back face** ("As this land enters, you may pay 3 life. If you don't, it enters tapped", `FellTheProfane // FellMire`): the back-face class defines `def shock_life = 3` (not `enters_tapped?`). `p1.play_land(land: card, face: :back, pay_life: true)` pays the life and enters untapped; without `pay_life:` (or with less life than N) it enters tapped and loses no life. `Game#legal_actions` offers both variants.

**Persist** (and granting it): `Keywords::PERSIST` (`persist?`); `Permanent` adds `TriggeredAbility::Persist` to a dying creature's death triggers when it has the keyword, printed or granted (`Abilities::Static::KeywordGrant`, e.g. `Isilu`). It returns the card under its owner's control with a -1/-1 counter unless the dead permanent had one. **"Creature spells you cast have convoke"**: a static ability defining `grants_convoke?(card, player)`; `Actions::Cast#convoke` accepts it alongside the card's own convoke. Example: `EirduCarrierOfDawn`.

**"Gains protection from each color until your next turn"**: `permanent.gains_protection_from_each_color_until_turn_of!(player)` (`Protection#until_turn_of`; dropped by `Permanent#receive_event` when that player's `Events::BeginningOfUpkeep` fires). **A delayed trigger granted to a creature until end of turn** ("gains 'whenever this creature deals combat damage ..., draw a card'"): `target.register_turn_trigger(Events::CombatDamageDealt, DrawTrigger)` with `should_perform? = event.source == actor && ...`. Example: `SyggWanderwineWisdom`.

**Double-faced planeswalkers, "until your next turn" pumps, emblems with static abilities**: a planeswalker DFC works like the creature ones (`Permanents::Planeswalker#loyalty_abilities` reads `face`; loyalty counters carry over a transform). `permanent.modify_power_until_turn_of!(player, -2)` ("gets -2/-0 until your next turn"; `ContinuousEffect#until_turn_of`, dropped at that player's `BeginningOfUpkeep`). `permanent.gain_all_creature_types!` is the permanent "gains all creature types". An `Emblem` subclass may define `static_abilities` (classes, `source` is the emblem, `controller` is its owner); `ContinuousEffects` applies them to the whole game. Example: `OkoLorwynLiege` (`-6`, `OkoShadowmoorScion::Emblem`).

**"Assigns combat damage equal to its toughness rather than its power"** (Bark of Doran): an Attachment card overrides `assigns_toughness_damage?(creature)`; `Permanent#combat_damage_amount` (power unless an attachment says toughness) is what `CombatPhase` divides and assigns, for attackers and blockers. **"During your turn, this creature has <keyword>" / "other tapped creatures you control have indestructible"**: a `KeywordGrant` with `conditions { game.current_turn.active_player == controller }` or a filtered `applicable_targets`. **"Whenever a player taps a basic land for mana, that player adds one mana of any type that land produced"**: a static `additional_mana(source, mana)` (as `MirarisWake`) that checks `source.basic_land?`. Examples: `BarkOfDoran`, `AdeptWatershaper`, `FeistySpikeling`, `Lavaleaper`.

**Keyword counters ("put a flying counter on it")**: `Counters["flying"]`, `["first strike"]`, `["lifelink"]` are `Counters::KeywordCounter` subclasses (`.keyword`); `ContinuousEffects#calculate_keywords` gives the permanent each counter's keyword even after `lose_all_abilities!`. Add another by subclassing in its own file. Example: `AbigaleEloquentFirstYear` (`trigger_effect(:add_counter, counter_type: "first strike", target:)`).

**Spell/trigger-granted play permissions** (`game.play_permissions`): `grant_until_end_of_next_turn(card:, player:)`, `grant_until_end_of_turn(card:, player:, free: false)` (`free: true` = "cast it without paying its mana cost", read by `Actions::Cast#free_from_exile?` via `free_cast?`; cast with no payment, e.g. `p1.cast(card:)`), and `grant_until_next_end_step(card:, player:)` (through this turn if it's your turn, else your next turn). Exile the card yourself first (`trigger_effect(:exile, target: card)`; exile is the shared `game.exile`). **Landcycling**: `landcycling({ generic: 1, red: 1 })` (or `filter:`) instead of `cycling(...)`; `Actions::Cycle` then adds a `Choice::SearchLibrary` to hand instead of drawing. Examples: `SizzlingChangeling`, `KulrathZealot`, `ShadowUrchin`, `DreamHarvest`, `BreOfClanStoutarm`. **"You may play it until you exile another card with this artifact"**: `grant_until_another_exiled_with(card:, player:, permanent: source)` stores the latest card in `permanent.state[:linked_exile]`; earlier permissions lapse automatically (`UnstableAmulet`). **"Cast from anywhere other than your hand"**: `Events::SpellCast#from_zone` / `cast_from_hand?` (set by `Actions::Cast#perform` from `card.zone` before the spell goes on the stack); spec with `p1.cast`, and reach the exile zone through a real exile (`game.exile.add`).

**Tokens that replace or aren't creatures**: a land token is a `Token.create` with `type T::Land` and abilities defined via `const_set` classes (`Tokens::Mutavault`: `{T}: Add {C}` and `{1}: become 2/2 with all creature types` through `become_creature!(types: Magic::Types::Creatures.values)`). "The first time you would create tokens each turn ... create copies of equipped creature instead" is a `ReplacementEffect` on `Effects::CreateToken` whose `call` returns another effect (here `CreateCopies`); once per turn via `receiver.triggered_once_this_turn?(key)` / `trigger_once_this_turn!(key)` (reset in `cleanup!`; specs use `current_turn.end!; current_turn.cleanup!`). Replacement effects have no "you may" yet, so it always applies. A one-shot "when that creature dies this turn" is `target.register_turn_trigger(Events::CreatureDied, Trigger)`. Examples: `MutableExplorer`, `MirrormindCrown`, `ScarbladesMalice`, `TendTheSprigs` (a `SearchLibrary` subclass whose `resolve!` continues after `super`).

**Split second**: `keywords :split_second`. `Stack#split_second?` is true while such a spell is on the stack; `Actions::Cast#illegal_reason` and `ActivateAbility#illegal_reason` (non-mana abilities only) raise `IllegalAction` then. Triggers and mana abilities are unaffected. Example: `SiegeSmash`.

**Connive**: `connive :enters, :attacks` in the DSL block wires "when this enters / whenever it attacks, it connives" (`TriggeredAbility::Connive`, `ConniveOnAttack`); use either one alone for a single trigger. For other trigger shapes, call `connive` in a triggered ability's `call` (`EffectShortcuts`, `Choice::Connive.add`). It draws immediately, then queues a mandatory discard choice; resolve with `game.resolve_choice!(card:)`. A nonland discard puts a +1/+1 counter on the actor. "Connives X" is `connive(target, amount: x)`: it draws X, discards `min(X, hand size)` and adds one counter per nonland discard; X = 0 does nothing. Examples: `ScurrilousSentry`, `SpymastersVault` (X, on a target creature).

**Replicate (energy)**: `replicate_energy 3` in the DSL block. Pay with `action.replicate(times)` while casting; `Cast` pays `cost * times` energy on finalize and `copy_for_replicate` copies the spell that many times via `CopyEffect.resolve_with_choice!` (skip the choice to keep targets, resolve it to pick new ones). Example: `ReiteratingBolt`.

**Cascade**: `def cast_triggers = [TriggeredAbility::Cascade]` in the card class. It exiles from the top until a nonland card with lower mana value, casts it free via `Choice::FreeCast.start`, and bottoms the rest in random order. A hit that needs a target asks for it; skipping that choice leaves the card in exile (not yet sent to the bottom). Examples: `AnnoyedAltisaur`, `MeteoricMace`.

**Overload** ("change 'target' to 'each'"): `overload generic: 4, green: 2` (a `Card` macro) and cast with `p1.cast_as(:overloaded, card:) { _1.pay_mana(...) }` (no `targeting`). The card's `resolve!(target: nil, overloaded: false)` picks `overloaded ? <every legal object> : [target]`. Example: `FangsOfKalonia`.

**Evoke** and **"if {W}{W} was spent to cast it"**: `evoke "{R/W}{R/W}"` (a `Card` macro; the alternative cost) and cast with `p1.cast_as(:evoked, card:) { _1.pay_mana(...) }`. A permanent that entered from an evoked spell has `evoked?` and `Permanent` adds `TriggeredAbility::EvokeSacrifice` to its enters triggers (so its own conditional enters triggers still run). `Costs::Mana#mana_spent` tallies the colour of every mana paid (generic and hybrid included), `Cast` passes it through `Card#resolve!` to `Permanent#mana_spent`, and an intervening-if enters trigger is `def should_perform? = super && actor.mana_spent?(:white, 2)` (counts *all* white spent, generic part included). Examples: the Incarnations `Catharsis`, `Deceit`, `Emptiness`, `Vibrance`, `Wistfulness`.

**Wither**: `Keywords::WITHER` (`wither?`). `Effect#deal_damage_to_target!(target, damage)` (used by `DealDamage` and `DealCombatDamage`) puts -1/-1 counters on a *creature* instead of marking damage when the source has wither; lifelink, events and prevention are unchanged. "Gains wither until end of turn" is `trigger_effect(:grant_keyword, target:, keyword: :wither)`; "those spells gain wither" is `spell.gain_keyword_as_spell!(Keywords::WITHER)` (cleared when the card leaves the stack). **Conspire**: `action.conspire(first, second)` inside a `cast` block (two different untapped creatures you control that share a colour with the spell); the copy is made as it's cast (`Cast#copy_for_conspire`: a `CopyEffect` with the may-choose-new-targets choice, or a token copy of a permanent spell). A card grants itself conspire with `conspire?`, or a static ability defines `grants_conspire?(card, player)` (Raiding Schemes). **"You may copy it" on cast**: a `Choice::May` whose `resolve!` calls `Magic::CopyEffect.resolve_with_choice!` (specs: accept, accept new targets, `resolve_choice!(target:)`). **"Remove any number of counters"**: a `Choice` answered with `remove: { CounterClass => n }`. Examples: `BarbedBloodletter`, `SpinerockTyrant`, `RaidingSchemes`, `RhysTheEvermore`.

**Blocking restrictions on the attacker**: `def maximum_blockers = 1` ("can't be blocked by more than one creature", checked per blocker in `CombatPhase#illegal_block_reason`) and `def must_be_blocked? = true` ("must be blocked if able", checked with menace when leaving declare blockers: `combat_damage!` raises `IllegalBlock` if some untapped, legal defending creature didn't block it). "Can't be blocked this turn" is `trigger_effect(:grant_keyword, target:, keyword: :cant_be_blocked)`. **A Cost that taps other creatures**: `Costs::MultiTap.new(1) { controller.creatures.untapped.except(source) }` alongside `Costs::SelfTap.new(source)` in `def costs` (a `ManaAbility` can do the same: `SpringleafDrum`; pay with `pay_multi_tap([...])`; `Player#activate_ability` already pays the `{T}`). **"When you next cast an instant or sorcery this turn"**: `register_turn_trigger(Events::SpellCast, T)` with a one-shot mark via `triggered_once_this_turn?`/`trigger_once_this_turn!` in `should_perform?` (`RimefireTorque`). **Aura that recolours and adds mana** (`ShimmerwildsGrowth`): `CharacteristicSetting` with `applies_to_target` + a static `additional_mana(land, mana)` (use `@source`, `StaticAbility` has no reader). In specs `current_turn.declare_attacker` alone doesn't notify `CreatureAttacked` -- follow it with `current_turn.attackers_declared!`. Examples: `SafewrightCavalry`, `VinebredBrawler`, `GravelgillScoundrel`, `WanderbrineTrapper`.

**Permanent, no-duration changes to other creatures** ("each creature target opponent controls loses all abilities, becomes a Coward in addition to its other types, and has base power and toughness 1/1"): `creature.lose_all_abilities!`, `add_types(T::Creatures["Coward"], until_eot: false)`, `modify_base_power(1, until_eot: false)`, `modify_base_toughness(1, until_eot: false)` (`CuriousColossus`). **An Aura that makes the creature something else**: `CharacteristicSetting` with `sets_types`, `sets_colors` (no args = colorless), `sets_base_power_and_toughness`, `loses_all_abilities` (`NoggleTheMind`). **A permanent becoming a chosen colour**: `permanent.change_colors!([color], until_eot: false)` (`color_override` is recomputed away, don't set it). **"Second from the top or on the bottom"**: like Swat Away's `TopOrBottom`, with `owner.library.add(card, [1, count].min)` (`TemporalCleansing`). Also `Card.landcycling` works with a creature (`Stratosoarer`).

**"Blight X" as an additional cost** (`Costs::BlightX`, `def additional_costs = [Costs::BlightX.new(self)]`): pay with `action.pay_blight_x(creature, x)` (0 to the greatest toughness among your creatures); the spell reads `x_blighted` in `resolve!` (`SoulImmolation`). **A spell that exiles itself**: `def exile_as_it_resolves? = true` (`Cast#resolve!` exiles instead of the graveyard). **"Until your next turn, prevent all damage that would be dealt to you"**: `player.prevent_all_damage_until_next_turn!` (`TargetedEffect#damage_prevented?` asks `target.prevents_damage?`). **A delayed "at the beginning of the next end step, return those cards"**: a small object with `receive_event(event)` passed to `game.subscribe` that unsubscribes itself once it fires (`MorningtidesLight::ReturnLater`). **"For each player, you choose a creature that player controls"**: a chain of `Choice::Targeted`, one per player, each adding the next, applying the effect when the last is answered (`Winnowing`).

**Levelling a creature** (Figure of Fable): keep the level in `permanent.state[:level]` (`Permanent#state`, a free-form hash) and read it from a `CharacteristicSetting` with dynamic `set_types`/`set_base_power`/`set_base_toughness` (they return nil while the level has no setting); the level abilities' `resolve!` checks the "if this is a Scout" condition. "Protection from each of your opponents" is a `Protection.new(condition: ->(card) { card.controller != owner })` added to `permanent.protections`. **"Copy target triggered ability you control"** (Kirol): target `game.stack.abilities` (`game.check_state_based_actions!` puts pending triggers on the stack without resolving them) and call `TriggeredAbility#copy_and_call!` (a trigger that chooses targets as it resolves chooses again for the copy). **"Look at the top X cards ... put any number onto the battlefield"** (Ajani, Outland Chaperone): a `Choice` holding the looked-at cards, answered with `targets: [...]`, that shuffles afterwards.

**"Whenever you cast an X spell, it gains haste"** (an emblem/permanent reacting to `Events::SpellCast`): find the spell's `Actions::Cast` on the stack (`game.stack.spells.find { _1.card == event.spell }`) and call `gain_haste_on_resolve!`; `Cast#resolve!` then grants haste to the permanent the spell becomes. An emblem's `receive_event` runs synchronously, so a "draw two cards" in the same emblem happens the moment the spell is cast. A planeswalker can give a creature type a mana ability with a `GrantActivatedAbilities` static ability (`granted_abilities` returns ability classes, e.g. a `TapManaAbility` with `choices :black`). "Up to one target" on a loyalty ability: `resolve!(target: nil)` plus `target_choices`; the activation may omit `targeting`. Example: `TyvarKell`.

**Dual-mana lands (`{B}{G}` bounce lands) and `ManaAbility#choices`**: a `ManaAbility` that fixes its mana by overriding `mana_produced` needs no `choices`; `ManaAbility#resolve!` only validates a choice when the ability responds to `choices` (before, such an ability raised `NameError`). Define `choices` (or the `choices :black, :green` macro) only when the player picks a colour. Examples: `GolgariRotFarm`, `OrzhovBasilica`, `SelesnyaSanctuary`. **Not modelled:** Partner (`MiaraThornOfTheGlade`) and "when mana from this source is spent, ..." riders (`PathOfAncestry`'s scry): the engine doesn't track which source produced the mana spent on a spell.

**"Up to N target ..." in a spell (`multi_target?`)**: `target_choices` returns one pool per target slot, so "up to four target cards from your graveyard" is the same graveyard pool repeated four times (after the first slot for any other target). `targeting(*targets)` accepts fewer targets than slots, and `Cast#can_target?` rejects more than the slots (and, with `distinct_targets? = true`, the same card twice). `resolve!(targets:)` gets the ones chosen. Example: `CatharticParting`. For a triggered ability, subclass `Choice::Targeted` with `choice_amount = 0..n` and `resolve!(targets:)` (see `MiasmaDemon`).

**Energy ({E})**: an ordinary player counter (`Counters::Energy`, `Counters["energy"]`); read it with `player.energy`, spend it with `player.pay_energy!(n)` (raises if short). "You get {E}{E}": `gain_energy 2` (shortcut for `add_counter "energy", to: controller, amount: 2`; `to:` names another player). "Pay {E}" as an activated-ability cost: `costs "{T}, Pay {E}"` parses to `Costs::PayEnergy` (`can_pay?`, paid in `finalize!`; `{E}{E}` pays two). "You may pay {E}. If you do, ...": subclass `Choice::PayEnergy` (like `Choice::PayMana`), run the "if you do" effects after `super` in `resolve!`, and only `game.add_choice` it when `choice.can_pay?`; `game.skip_choice!` declines. "You may pay any amount of {E}" (Galvanic Discharge, Aether Spike): subclass `Choice::PayAnyEnergy`, override `paid(amount)` (runs with 0 when declined); answer with `game.resolve_choice!(amount: n)`, clamped to the energy you have. "Cast <spells> by paying {E} rather than their mana costs (and as though they had flash)": a static ability answering `alternative_cost_for(card, player)` with `Costs::EnergyAlternativeCost.new(amount: 1, grants_flash: true)` (nil when the spell doesn't qualify); cast with `p1.cast(card:, pay_static_alternative: true)` — the energy is taken on cast and `Actions::Cast#instant_speed?` honours `grants_flash?` only for that cast (`PrimalPrayers`). Energy persists across turns and never leaves the player. "Tap/sacrifice this unless you pay {E}" is a `Choice::PayEnergy` subclass whose `decline!` does the penalty, run directly when `can_pay?` is false (`Electrozoa`, `StaticPrison`). `Choice::PayEnergy.new(actor:, amount: 3)` pays several at once (`ThrivingSkyclaw`, `HexgoldSlith`). A mana ability with an energy cost is a `Magic::ManaAbility` with `costs "{T}, Pay {E}"` and `choices :all` (`SolarTransformer`); a short `Costs::PayEnergy` raises a RuntimeError from `pay_energy!`, not `IllegalAction`. "Energy equal to the number of creatures you control" after creating tokens: `gain_energy controller.creatures.count` (`ScurryOfGremlins`). "If you would get {E}, you get that many plus one instead": a `ReplacementEffect::CounterAmountChange` with `matchers = [Effects::AddCounterToPlayer]` that checks `Counters[effect.counter_type] == Counters::Energy` and `effect.target == receiver.controller` (`IzzetGeneratorium`). `Player#pay_energy!` notifies `Events::EnergyPaid`; "paid or lost N {E} this turn" reads `game.current_turn.energy_paid_by_player(player)`. Examples: `ConduitGoblin`; spec `spec/energy_spec.rb`.

**"Each player may <do X>" with the energy paid** (`WheelOfPotential`): a `Choice::PayAnyEnergy` whose `paid(amount)` adds one `Choice::May` per player with `def chooser = @player`. `game.choices` is newest-first, so add the opponents' choices before yours to have you decide first. Copy `hand.cards.to_a.dup` before moving cards out of it, or the loop skips cards. "Play those cards until the end of your next turn": `game.play_permissions.grant_until_end_of_next_turn`.

**Equip with an energy cost** ("Equip--Pay {E}{E}"): `equip [Costs::PayEnergy.new(nil, amount: 2)]` (the source isn't needed because `ActivateAbility` passes the player to `can_pay?`). Two ETB triggers on one card ("you get {E}{E}" and "attach it to target creature you control") are two classes in `etb_triggers`. Example: `InventorsAxe`.

**Populate** ("Create a token that's a copy of a creature token you control."): call `populate` (an `EffectShortcuts` method, like `proliferate`) from the trigger's `call`. It is a `Choice::Targeted` with `targets? = false` over the controller's creature tokens, queued with `game.add_choice` (not `game.choices.add`) so a single token auto-resolves and no choice is added when there are none. With two or more tokens, answer with `game.resolve_choice!(target: token)`. Example: `MusterTheDeparted`.
**Ward--Sacrifice N permanents** (any, lands included): `ward sacrifice_any: 2`; answer the `Choice::Ward` with `sacrifices: [...]` (exactly N distinct permanents the payer controls). **Annihilator X with a computed X**: subclass `TriggeredAbility::Annihilator`, override `instance_amounts` (e.g. `[X]`), and merge it into `event_handlers` (`UlamogTheDefiler`).

**Annihilator N** ("Whenever this creature attacks, defending player sacrifices N permanents"): `keywords Keywords::Annihilator.new(2)` includes `KeywordHandlers::Annihilator`, which adds `TriggeredAbility::Annihilator` to `CreatureAttacked` via `add_event_handler` (a card that overrides `event_handlers` must merge `super`). Each `Keywords::Annihilator` instance (printed or granted) triggers separately (702.86b): the one registered handler takes the first instance's N when it triggers and queues a sibling ability per further instance; N is recorded at trigger time. Then the defending player (or the attacked planeswalker's controller) gets a `Choice::SacrificePermanents` (`game.resolve_choice!(sacrifices: [...])`; `skip_choice!` sacrifices the first N; no choice is offered when they control N or fewer permanents). A card that only gains the keyword (conditional `KeywordGrant`) adds `Events::CreatureAttacked => TriggeredAbility::Annihilator` to its own `event_handlers`. Spec: `spec/annihilator_spec.rb`.

**Bestow** ("Bestow {cost}"): add `bestow Costs::Mana.new(...)` to the DSL block (includes `Cards::Bestowable`). Cast it with `player.cast_as(:bestowed, card:) { |a| a.pay_mana(...).targeting(creature) }` (`Actions::Cast::Bestowed`). On resolution `Bestowable#resolve!` attaches it to the target as an Aura and sets `permanent.bestowed`; if the target is gone it resolves as a plain creature. While `bestowed_now?` (bestowed and attached) the permanent is an Enchantment — Aura, not a creature (`ContinuousEffects#calculate_types`). When the host leaves, the state-based action detaches it instead of binning it, so it becomes a creature again. The Aura half feeds the host through the usual attachment methods (`power_modification`, `toughness_modification`, `keyword_grants`, ...); `Bestowable` supplies neutral defaults, so a card overrides only what it grants. A granted triggered ability needs its own event handler gated on `actor.bestowed_now?` (`TritonWavebreaker::EnchantedCreatureProwess`); a static transformation uses `applies_to_target` plus `conditions { source.bestowed_now? }` (`TrickstersElk`). A bonus that scales with counters on the Aura: define `enchanted_bonus_per_plus_one_counter` on the card (`Permanent#power_modification` multiplies it by the +1/+1 counters on the Aura; `GlyphElemental`). Mentor has `Keywords::MENTOR` but no shared handler: the card supplies a `CreatureAttacked` trigger whose attacker is `actor.bestowed_now? ? actor.attached_to : actor` (`NyxbornUnicorn::MentorTrigger`, targeting attacking creatures with lesser power). A granted keyword with a rules-defined trigger (`keyword_grants = [Keywords::AFTERLIFE]`, `IndebtedSpirit`) works when `Permanent#lifecycle_triggers_for` knows the keyword.

**Afterlife 1** (`keywords :afterlife`): `Permanent#lifecycle_triggers_for` adds `TriggeredAbility::Afterlife` on `CreatureDied` for any creature with `Keywords::AFTERLIFE`, printed or granted; it makes a 1/1 white and black flying Spirit. Only afterlife 1 is modelled.

**Saga that remembers an exiled card** (The Creation of Avacyn): chapter I adds a `Choice::SearchLibrary` subclass with `to_zone: :exile` whose `resolve!` exiles the pick, stores it in `actor.state[KEY]` (the saga permanent's free-form hash), shuffles, and ends with `normalize_targets :resolve!`. Later chapters read `actor.state[KEY]`; a `Choice::May` subclass with `resolve!`/`decline!` handles "you may put it onto the battlefield, otherwise into hand".

**Eternalize / Embalm-style graveyard copy** (Fanatic of Rhonas): a `graveyard_abilities` `ActivatedAbility` with `costs "{2}{G}{G}, Exile {this}"` and `requirements_met?` checking `source.zone&.graveyard?` plus `game.can_cast_sorcery?`. `resolve!` does `[*copy_as_token(source)].each` and then `modify_base_power/toughness`, `change_colors!` and `add_types` (all `until_eot: false`). A mana ability can override `mana_produced` (`{ green: 4 }`) and `requirements_met?` for "activate only if" conditions.

**Conditional convoke + "discard, then exile and pick one"** (Party Thrasher): a `StaticAbility` answering `grants_convoke?(card, player)` can restrict by zone (`card.zone&.exile?`) and type. A "may discard, if you do ..." trigger queues a `Choice::May` subclass whose `resolve!(card:)` discards and then queues a second `Choice` with `resolve!(target:)` that calls `game.play_permissions.grant_until_end_of_turn`. In specs, `go_to_main_phase!` already fires `Events::FirstMainPhase`, so that choice is pending (`game.skip_choice!`) before any stack work.

**Becomes a copy until end of turn** (Shifting Woodland): `permanent.become_copy_until_eot!(card)` sets `copied_card` and clears it in the cleanup step; a graveyard-targeting activated ability uses `target_choices` over `controller.graveyard.cards`, gated by `graveyard.delirium?` in `requirements_met?`.

**Hexproof from abilities / exchange control** (Volatile Stormdrake): `def hexproof_from_abilities? = true` on the card; `Permanent#can_be_targeted_by?` treats a `Permanent` or ability object source as an ability (spells pass the card). Exchange control swaps `permanent.controller =` on both; capture the player before the swap, since `actor.controller` changes.

**Exert mana + haste** (Arena of Glory): a mana ability calls `source.cannot_untap_next_turn!` for "Exert" and `controller.grant_haste_mana!`; `Cast` then gives the next creature spell cast that turn haste (`gain_haste_on_resolve!`). The engine does not track which mana pays for what, so this is an approximation.

**Improvise** (Archway of Innovation): `action.improvise(artifact)` taps an artifact to pay `{1}` (call it before `pay_mana`, like `convoke`). It needs `card.improvise?` or `player.next_spell_improvise?`, which "the next spell you cast this turn has improvise" sets with `player.grant_next_spell_improvise!` and `Player#consume_spell_cast!` clears when any spell is cast.

**Modular N** (Arcbound Condor): an `AdditionalCountersForEntering` static ability returning N for `source`, plus a `TriggeredAbility::Death` whose `call` reads `actor.counters.count` (the dead permanent keeps its counters) and adds a `Choice::Targeted` over your artifact creatures. Skip the choice when no artifact creature is left.

**Umbra armor** (Lion Umbra, Dog Umbra): an Aura card answers `umbra_armor?(host, aura)`. `Permanent#destroy!` calls `use_umbra_armor!` first: it clears the host's damage, sends the Aura to the graveyard and skips the destruction, so lethal damage from state-based actions is saved too. Because the answer takes the host, an armor that depends on the host works (`DogUmbra` only has armor while its controller controls the creature). The same shape handles a host-dependent "can't attack or block": answer `forbids_enchanted_combat?(host, aura)`, read by `Permanent#can_attack?`/`can_block?`. "Enchant modified creature" is a `target_choices` filter plus `can_enchant?` using `Permanent#modified?` (`LionUmbra`).

**Doubling counters / copying attachments** (Arna Kennerüd, Skycaptain): a `CreatureAttacked` trigger on another creature checks `event.attacker.modified?`. Doubling adds, per `counters.map(&:class).uniq`, as many counters as `counters.of_type(type).count` through `add_counter` (so replacement effects apply). Copying an attachment is `copy_as_token(attachment.card)` (pass the Card, not the Permanent) followed by `attach_to!(attacker)` on each returned token. A card name with a non-ASCII letter loses it in the spec helper's constant lookup, so the constant is `ArnaKennerdSkycaptain`.

**Granted retrace** (Six): a `StaticAbility` answering `permits_casting_from_graveyard?(card, player)` and `additional_cost_for(card, player)` returning `Costs::Discard.new(player, ->(c) { c.land? })` (same shape as `ExplorationBroodship`'s sacrifice). The spec pays it with `pay_discard(land_card)` on the cast action. "Mill N, you may put a land among them into your hand" is `controller.mill(n)` (returns the milled cards) plus a `Choice::Targeted` with `choice_amount = 0..1` over the milled lands.

**Granted dredge** (The Necrobloom): a battlefield `StaticAbility` answers `dredge_amount(card, player)`; `Player#dredge!(card)` mills that many and returns the card from the graveyard to hand. The engine has no optional draw replacement, so dredge is an explicit call made instead of `draw!`, not an automatic replacement (`DakmorSalvage`'s own dredge replaces every draw).

**Storm** (Amphibian Downpour): a `cast_triggers` entry (`TriggeredAbility::CastThisSpell`) counts `game.current_turn.spells_cast.count - 1` and adds one targeted `Choice` per copy. Each choice makes a token via `Permanent.token_copy(game:, owner:, card:)` and calls `attach_to!(target)`. The trigger sits on the stack, so a spec must `game.settle!` and `game.stack.resolve!` before `game.resolve_choice!`.

**Copy a spell** (Flare of Duplication): target `game.stack.spells` (instant or sorcery) and call `Magic::CopyEffect.resolve_with_choice!(actor: self, receiver: target.card, targets: target.targets)`. In a spec, answer the "may" with `game.resolve_choice!`, then pick the new target with `game.resolve_choice!(target:)`.

**Replicate with mana** (Consign to Memory): `replicate_mana generic: 1` in the DSL block. `action.replicate(n)` adds n times that cost to `mana_cost`, so `pay_mana` must cover it; the copy runs through `copy_for_replicate`.

**Prototype** (Frogmyr Enforcer): `prototype cost: { generic: 3, red: 1 }, power: 2, toughness: 2` in the DSL block. `Actions::Cast::Prototyped` (offered by `LegalActions`) pays the prototype cost and sets `card.prototyped`, which makes `Card#colors`, `#mana_value` and `Cards::Creature#base_power`/`#base_toughness` use the prototype values until the card leaves the stack and battlefield (`Card#zone=` resets it). Affinity is a `self_mana_cost_adjustment` (`{ generic: -> { -count } }`).
